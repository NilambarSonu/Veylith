# Independent source audit

Base: `1086aef` on `dev/phase-2d-reliability`. The initial working tree was clean. All 187 prior tests passed before changes. No remote resources or third-party tools were installed.

| Finding                                                          | Evidence and implication                                                                                                                                                                                                | Phase 2E disposition                                                                                                                                                                                                             |
| ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Global discovery cache reused stale tool metadata for invocation | `apps/gateway/src/server.ts` passed a cached tool into the TOCTOU comparison. Development X2-01/03/05 forwarded changed tools inside TTL.                                                                               | Fixed: bounded discovery cache scoped by upstream URL, policy version, mode, client label, session and baseline revision; invocations refresh discovery and recheck with the forwarding connection. TTL alone is not security.   |
| Uncaught partial-request read failure                            | Development run ended in uncaught `ECONNRESET`; request-body loop was outside catch/finally.                                                                                                                            | Fixed: admission and body/response handling share exception-safe lifetime management; aborted requests do not crash the process.                                                                                                 |
| Uploads did not occupy concurrency slots                         | Counter incremented after complete body collection; slow uploads bypassed admission.                                                                                                                                    | Fixed: admission begins before reading, decrements in finally. Actual 429 verified.                                                                                                                                              |
| HTTP 413 socket handling                                         | Original code destroyed the socket immediately after `res.end`. Default limit is 1,048,576 bytes, while Phase 2D tests override 262,144 bytes.                                                                          | Fixed: send 413 with connection close and consume/discard safely; no pre-flush socket destruction. Separate 8,192-byte lab override and actual default verified.                                                                 |
| Output ignored backpressure                                      | HTTP pump ignored `res.write` return value and recursively pulled more data.                                                                                                                                            | Fixed: iterative pump waits for drain and cancels the reader on disconnect. A paused consumer receives a 2 MiB harmless response intact.                                                                                         |
| Session enforcement incomplete at HTTP admission                 | `ENFORCE_SESSIONS` only guarded resource subscriptions; no-session tools/resources/prompts could pass.                                                                                                                  | Fixed: validate local session on all MCP admissions after bounded body intake. Oversized requests still receive 413 before session processing.                                                                                   |
| Caller label is not authentication                               | A stolen valid session plus matching forged `x-veylith-client-id` is accepted.                                                                                                                                          | Unresolved by design of local bearer sessions; bind configuration to loopback and report the negative H3 finding. Do not describe labels as production identity.                                                                 |
| Custom TTL became default one-hour TTL                           | `validateSession` always extended by default TTL, including short-lived sessions.                                                                                                                                       | Fixed: retain the requested per-session TTL during touch and delete TTL state with the session.                                                                                                                                  |
| Semantic cache scope not supplied by engine                      | Cache supported server scope, but five engine call sites omitted it; sessions, mode and baseline revision were absent; colon-joined fields could collide.                                                               | Fixed: JSON tuple keys include upstream, client, session, policy, model/mode and baseline revision. Disabled semantic results now have deterministic origin instead of being mislabeled live.                                    |
| Durable audit writers could produce conflicting chains           | Independent processes/chains used different in-memory tails, with no writer exclusion. Partial write counts were ignored; appending after close silently became memory-only.                                            | Fixed: exclusive append lock, observed file-size check, complete byte-write loop, sticky failure and rejection of closed durable sinks. Concurrent stale writers are rejected, rather than fabricating a valid chain.            |
| Audit anchoring and retention                                    | A valid-prefix truncation after restart or whole-chain regeneration cannot be authenticated using only local hashes; all records remain in memory.                                                                      | Unresolved: external checkpoint/signature and bounded retention needed. Abrupt process-death probe only guarantees records acknowledged after fsync; it is not a power-loss proof. Stale append locks require reviewed recovery. |

No patterns were tuned against the frozen holdout.                                                                                                                                                  |

Handler forwarding calls do not propagate downstream cancellation to upstream SDK calls.                                                                | Notification delivery unsupported; cancellation recovery is tested, but remote-work cancellation is not claimed.                                                                                                                 |

The first HTTP fix briefly broke two unchanged regression assertions (404 JSON and 413 precedence). Both were corrected, and their failed-run output is retained in the baseline evidence. No previous test was removed, skipped or relabeled.

The actual hardware is measured by Node `os` APIs and safe `sysctl`/`sw_vers` commands: 34,359,738,368 bytes of memory (32 GiB), Apple M5, ten logical CPUs, Mac17,4, macOS 27.2. The former 8 GB statement is incorrect for this machine.

Established third-party gateway comparison was not performed: no approved existing installation was available, and the task forbids installing unknown security tools without approval. Direct MCP, deterministic-only and deterministic mock modes are measured locally. Real Muse remains manual and unevaluated.
